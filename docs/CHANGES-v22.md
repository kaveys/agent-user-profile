## 这支片子在讲什么

不是介绍功能清单，而是回答一句：「它和别的记忆插件比，强在哪」。

四条优势都落在可验证的能力差异上，不喊口号：

| 优势 | 可验证的差异 | 片中证据画面 |
| --- | --- | --- |
| 双向核对 | `set` 能改的每个键，`panel.settings` 必须看得到；反过来，面板上每个键都必须改得动。两个方向一起查，漂移无处躲 | 设置页截图 + 两个方向的行文说明 |
| 证据可查 | `explain` 给出「这条为什么被带入本轮」的相关度；`health` 给出五项打分与短板建议 | 概览页截图 + 两条命令结论 |
| 配套自检 | 七套测试常驻仓库：selftest / audit 33 / audit2 34 / audit3 51 / audit4 22 / audit5 31 / audit6 25 / 安装体检 13 | 测试矩阵画面（数字与仓库一致） |
| 免重启、可回滚 | CLI 现起进程即时生效、界面走热重载、只有新增面板动作要重启一次；每次写入前留快照 | 生效矩阵画面 |

收尾前有一段**实测演示**：把 `inject.relevanceFloor` 改成 0.2，`panel` 读回来就是 0.2；改回 0.12，面板跟着回到 0.12。这段的文本取自本机真实执行输出，不是画的示意图。

## 制作参数

- 画幅 1280×720、30fps、CRF 20、`yuv420p`、`+faststart`。
- 配音：SAPI `Microsoft Huihui Desktop`，Rate 0（默认语速），逐场单独合成 wav。
- 音乐：ffmpeg 离线合成三音低频铺底（110 / 164.81 / 220 Hz，`lowpass 700`，总音量 0.05，混音权重 0.55）+ 2 秒淡入、末尾 3 秒淡出。实测成片 `mean_volume -24.2 dB / max -0.4 dB`，人声主导。
- 字幕：烧进画面底部 96px 半透明条，25px 微软雅黑居中；同时导出 `.srt` 供平台挂载。

## 踩坑（值得记）

1. `list.txt` 若用绝对路径写进 concat 清单，中文目录名会被按本地代码页读成 `?`，ffmpeg 报 `Impossible to open`。改成**相对文件名 + 先切工作目录**。
2. `afade=t=out:st=` 的值必须先算成变量再拼进 filter 串；直接字符串相加会拼出空值，报 `Unable to parse "st" option value ""`。
3. 幻灯片里的中文字必须用 GDI+ 直接绘制（`Microsoft YaHei` + `Pixel` 单位），不要交给 ffmpeg 的 `drawtext`——一是字体路径转义，二是中文文本文件编码，两个坑都比画图贵。
4. 逐场 ffmpeg 加 `if (-not (Test-Path $mp4))` 复用已渲染的场次，重跑只补混音，迭代成本从 2 分钟降到 10 秒。
