[01-hook] 你有没有遇到过这种事。同一个 AI，昨天刚说过的话，今天它就不记得了。
[02-pain] 你说过，你喜欢简单一点。第二天，它又开始绕圈子。你说那个文件夹别动，它还是动了。每换一个新对话，你就得从头再讲一遍。
[03-what] 现在，有一份关于你的说明书。说一次，写清楚。以后每次开口之前，它都会先看一眼。
[04-categories] 里面写的是：你是谁，你喜欢什么，你习惯怎么做，还有你绝对不想要什么。一共十类。每一条，你都能看，能改，也能删。
[05-control] 哪条不合适，点一下，就能调轻重。说错了，删掉。删错了，随时还原。它还会告诉你，这次为什么这么做。
[05b-tidy] 记得多了，它自己也会整理。同一件事记了两遍，合成一条。哪天你换个 AI 用，也能把这些整段搬过去。
[06-payoff] 所以新对话的第一句话，它已经知道你要什么了。哪天你不想让它参考，就说一句：这次别用我的资料。它就停。
[07-outro] 开源，免费。数据只留在你自己的电脑里。想试试，搜索 agent user profile。
