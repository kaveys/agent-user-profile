[01-hook] 你有没有过这种感觉：同一个 AI，昨天刚说过的话，今天它全忘了。
[02-pain] 你告诉它你喜欢简洁的东西，第二天它又开始啰嗦；你说过别动那个文件夹，它还是会动。每次开新对话，都得从头解释一遍。
[03-what] 现在，有一份关于你的说明书。一次写清楚，往后每次开口之前，它都会先看一眼。
[04-categories] 里面记的是这些：你是谁、你喜欢什么、你习惯怎么做、你绝对不要什么。分成十类，每一条都能看、能改、能删。
[05-control] 不满意的那条，点一下就能调轻重；说错了就删掉，删错了随时还原。它还会告诉你，这次为什么按你的习惯来。
[06-payoff] 于是新对话的第一句，它就已经懂你了。万一这次不想让它参考，说一句「这次别用我的资料」，它立刻停。
[07-outro] 开源、免费，数据只留在你自己的电脑里。想试试，搜 agent user profile 就能找到。
