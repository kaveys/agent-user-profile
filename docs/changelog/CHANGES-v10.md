# CHANGES v10 — 界面重做：看得清、点得对

> 起因：用户「UI优化」→「美化界面，还是不够漂亮美观」→ 真机截图逐页核对后重做视觉层。
> 这一版只改 `client.js`（外加一条删除前的二次确认），不动数据层与注入逻辑。

## 一、真机诊断（改之前的样子）

设置页内容列宽只有约 630px，所有元素同一个权重，读起来没有层次：

| 观察 | 问题 |
| --- | --- |
| 标题、状态胶囊、版本行、两个按钮挤在同一行 baseline | 视线没有落点 |
| 四张 KPI 卡数值 15px，与标签几乎同大 | 「11 条」不突出 |
| 「各维度条目数」10 行全写着 `0 条`，右侧大片空白、进度条全空 | 看起来像坏了 |
| 「当前策略」标签「个性化需求」被挤成两行 | 排版失守 |
| 页签平铺、字号与正文同级 | 分不清现在在哪一页 |
| 卡片 padding 12、间距 12，边框和底色几乎同色 | 没有呼吸感 |

## 二、改了什么

### 1. 一套最小设计体系（写在 `styles` 里，仍是内联样式，零构建）

- 间距：卡片 gap 18 / 卡片内 padding 16 / 行内 8~10 / 组间 14。
- 字号：24（KPI 数值）/ 17（页面标题）/ 13（区块标题）/ 12.5（正文与表格）/ 11.5（元信息）/ 11（辅助）。
- 圆角：卡片 12、按钮 8、胶囊 999。
- 数字统一 `font-variant-numeric: tabular-nums`，位数变化不跳。
- 颜色仍然只用 `--dsw-alias-*` 主题变量，不写死色值。

### 2. 概览页重排

- 头部拆两行：标题 + 状态胶囊 + 刷新/立即更新 一行，`v83 · 11 条已确认 · 按优先级排列` 一行小字。
- KPI 数值放大到 24px，「画像条目」用品牌色；次级说明 11px。语义色只在异常时出现（待审 > 0 才是 warn 色）。
- 「各维度条目数」改名「画像分布」：只列出**有条目**的大类、按条数降序、数值右对齐带条；一个大类都没有时**整块不渲染**，不再摆 10 行 `0 条`。
- 优先级分布 + 当前策略由两列改成竖排（630px 两列必然会折行）；策略改成 `88px 1fr` 两列网格，标签 `nowrap`，值一行说完。
- 画像为空时给一张「画像还是空的」卡，直接讲三条让它长起来的路径，而不是干摆一个 0。

### 3. 条目页

- 列宽固定：维度 84px（不再「审美与口 / 味」逐字折行）、权重 72px、操作 138px。
- 操作按钮一行排开（`flex-wrap: nowrap`），不再折到第二行。

### 4. 设置页

- 没有改动时不再摆一条「所有设置与磁盘一致 + 两个灰按钮」，只留一行小字说明；
  一旦有改动，才出现带品牌色描边的粘性条「N 项待保存 + 保存并重建 / 放弃修改」。

### 5. 备份与重置

- 恢复点默认只显示最近 5 份，更多收进「展开全部 N 份」；恢复仍是两步确认（5 秒内再点一次）。

### 6. 危险动作的护栏（顺带修的真问题）

- 批量删除原来是**一次点击直接批量 forget**，没有任何确认 —— 画像被清空三次都是这条路径。
  现在第一下变成「确认删除 N 条」并显示条数，5 秒内再点才执行；执行后提示「到备份与重置 → 恢复点可整批还原」。

## 三、追加：顶部太挤（第二轮真机反馈）

用户看完第一版说「上面挨得太近了」，于是又量了一遍间距（截图像素 ÷ 0.5469 = 屏幕像素）：

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 内容区顶部留白 | 8px | **30px** |
| 标题行与版本行 | 6px | **12px** |
| 标题区下沿 | 无线 | **14px 留白 + 1px 细线**，和页签区分开 |
| 页签点击区 | 8px | **10px 0** |
| 页签条与标题区 | 贴住 | `marginTop:-6px` 抵扣卡片间隔，视觉上留 18px |
| KPI 卡内边距 / 间距 | 12×14 / 10 | **14×16 / 12** |
| 卡片内边距 | 16 | **18** |
| 提示条位置 | 页签之下 | **页签之上**（先说发生了什么，再看具体页） |
| 主指标强调 | 无 | 「画像条目」卡左侧 **2px 品牌色竖线** |
| 页签之间 | `gap: 2px` + 内边距 0（文字贴在一起） | **`gap: 22px`**，页签内边距 `9px 1px` |
| 页签计数胶囊 | `margin-left: 5px` | **7px**（不与标题黏连） |

第三轮反馈（m03954「挨得太近了」+ 页签截图）针对的正是页签条：七个页签原来只隔 2px、且每个页签左右内边距为 0，所以「概览条目待审冲突与历史维度 10 设置备份与重置」读起来是一整串。现在页签之间固定 22px 空气，下划线长度仍等于文字宽度，选中态不受影响。

真机复核：顶部从「挤在一起」变成三段清晰的节奏——标题区（含细线）→ 提示/页签 → 内容卡片。

## 五、生效方式

- `client.js` 走 dsh-client-hmr 热重载：改完刷新设置页即可，本版已重新同步到 `~/.dsh/plugins/dsh-user-profile/`。
- 本版没有新增 action，不需要重启 dsh（`restore` 是上一版新增的，仍未重启的话依然会 400）。

- 待审页 / 冲突页的视觉尚未按新体系逐项复核（已能正常渲染，构图与旧版一致）。
