# v23：面向普通用户的介绍片（72 秒 · 中文配音）

## 为什么重做

v22 那支 154 秒的片子是**写给开发者看的**：讲自检用例数、贴终端命令、用系统合成音。用户看完成片给了三条具体意见：

- 「不要带入很多专业的代码之类的，只是为了吸引流量，用的人可能是对这一块很陌生的人」
- 「配音太过机械，换一个好一点的配音，清晰度提升」
- 「图片适度放大，看不太清楚」

所以这一版换了讲述对象：**一个不知道 Agent 是什么、但每天在用 AI 聊天的人**。全片没有命令行、没有代码、没有测试数字，也不讲「我们改了什么」。

## 制作方式（全离线，不依赖任何第三方素材）

- 画面：`scripts/build-trailer.ps1` 用 GDI+ 直接画 1920×1080 PNG。设计按 1280×720 网格写，`Px(v) = v * 1.5` 放大到 1080p，改一处比例不用重排所有坐标。
- 配音：`scripts/tts.py` 封装 edge-tts（`zh-CN-XiaoxiaoNeural`，rate `-4%`），比系统 SAPI 自然得多。
- 合成：每场「静帧 + 配音」渲染成 mp4（带 0.3 秒淡入 / 0.4 秒淡出），再用 `concat -c copy` 拼接；整体铺一层极轻的低音垫（98/146.83/196/293.66 Hz 四路正弦，`volume=0.042`、`lowpass=600`），与旁白 `amix` 时不归一化，避免人声被压低。
- 质检：`tests/qa-frames.mjs` 把每张帧缩到 480×270 读像素，算内容包围盒，左右上下边距过小或正文压到字幕带就报 `CHECK`。

## 本轮踩到的坑（都写进脚本注释了）

1. **删帧不生效导致假重渲**：`Get-ChildItem scripts\trailer-build -Include *.png` 不带 `-Path ...\*` 时不匹配任何文件，静默不删，脚本走「已存在就跳过」分支，2.7 秒就「出片」了 —— 实际是旧帧。正确写法 `Get-ChildItem -Path scripts\trailer-build\* -Include *.png,*.mp4,*.wav,*.mp3 -File | Remove-Item -Force`。
2. **PowerShell 变量名大小写不敏感**：`foreach ($c in $cells)` 直接覆盖了调色板 `$C`，后面所有颜色都变 null，报「无法将 null 转换为 System.Drawing.Color」。改成 `$cell`。
3. **函数返回值不能参与算术**：`($y + S(64))` 报「必须在"+"运算符后提供值表达式」，把 `S(n)` 全部内联成 `(n * $U)`。
4. **ffmpeg 的 `drawtext` 别用来画中文**：字体路径与编码两个坑；中文一律 GDI+ 画好再进 ffmpeg。
5. **QA 的 maxBuffer**：全分辨率 raw 帧 6.2 MB 超过 `execFileSync` 默认 1 MB，报 `ENOBUFS`；缩到 1/4 分辨率后 380 KB 正常。
