### 顺带修掉的一个设计缺陷

`declare` 不给 `--key` 时，默认 key 是**维度名** —— 同一大类里第二条会把第一条顶掉（等于静默丢数据）。现在默认 key 取正文指纹（`factKey()`，djb2/base36）：同一句话再说一遍更新那一条，不同的话各自成条。
